# Registros de decisão (ADR)

Cada arquivo registra uma decisão de arquitetura: o problema, a escolha feita e o motivo.
Leia-os para entender por que o sistema funciona de certo jeito antes de mudar esse jeito.

São registros históricos: ficam como foram escritos. Termos como "etapa 3" ou "plano de
execução" se referem ao planejamento interno do desenvolvimento, que não faz parte do
repositório. Quando uma decisão é substituída, vale a mais nova. A 0008, por exemplo, tornou
opcional o MFA que a 0002 exigia.
